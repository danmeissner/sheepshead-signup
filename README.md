# sheepshead-signup
Signup for Weekly game.

## Viewing the Site

To view the rendered HTML website instead of the source code:

### Option 1: GitHub Pages (Recommended)

Once GitHub Pages is enabled, visit:
**https://danmeissner.github.io/sheepshead-signup/**

To enable GitHub Pages if not already set up:
1. Go to repository Settings
2. Click "Pages" in the left sidebar
3. Under "Source", select "GitHub Actions"
4. The site will automatically deploy on every push to the main branch

### Option 2: Local Viewing

To view the HTML locally:
1. Clone the repository: `git clone https://github.com/danmeissner/sheepshead-signup.git`
2. Open `index.html` in your web browser

## About

This site allows players to sign up for monthly Sheepshead card game nights at Meissner's house on the last Friday of each month at 7:00 PM.
